# AI Translator

A Python AI-powered translation application built with the OpenAI API.

## Features

- Translate text into a target language

- Input validation

- Custom application exceptions

- OpenAI integration

- Request timeout

- Retry handling

- Logging

- Unit testing

- Mocking external API calls

- Environment-based configuration
